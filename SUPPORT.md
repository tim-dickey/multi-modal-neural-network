# Support

## Documentation

Before opening an issue, please check the existing documentation:

- [`README.md`](./README.md) — project overview, installation, and quick-start
- [`TRAINING_GUIDE.md`](./TRAINING_GUIDE.md) — end-to-end training walkthrough
- [`IMPLEMENTATION_SUMMARY.md`](./IMPLEMENTATION_SUMMARY.md) — architecture and design decisions
- [`docs/`](./docs/) — additional reference material

## Asking a Question

If the documentation doesn't answer your question, open a
[GitHub Discussion](../../discussions) in this repository. Discussions are the
preferred channel for:

- Usage questions ("How do I…?")
- Help understanding model outputs or training behaviour
- General feedback and ideas

Please search existing discussions before opening a new one.

## Reporting a Bug

Use the **Bug Report** issue template. Provide:

- Python and PyTorch version (`python --version`, `python -c "import torch; print(torch.__version__)"`)
- Operating system and CUDA version (if applicable)
- Minimal reproduction script or notebook
- Full traceback / error output

## Requesting a Feature

Use the **Feature Request** issue template. Describe:

- The problem or limitation you are facing
- Your proposed solution or approach
- Any alternatives you considered

## Security Vulnerabilities

Do **not** open a public issue for security concerns. Follow the process
described in [`SECURITY.md`](./SECURITY.md).

## Response Time

This is a community-maintained project with no guaranteed response SLA. Issues
and discussions are reviewed on a best-effort basis.
